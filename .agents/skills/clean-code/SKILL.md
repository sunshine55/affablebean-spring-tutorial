# Clean Code Skill

## When to Use

- Review detailed design before implementation
- Refactor legacy code

## Guidelines

- Use [code smell](references/code_smell.md) guidelines to detect low maintainability code
- Follow [OOP](references/object_oriented_programming.md) guidelines to object-oriented code
- Follow [functional programming](references/functional_programming.md) guidelines to function-oriented code
